Hi. My name is Dhruv Rao and this is my application of the problem solving skills I've learnt over the years for the hotplate problem and its breakdown. I first started with the knowledge that commercial HotPlates are worth upwards of 1 lakh so I have to work with a budget of around 60% of that. So the following decisions and changes were made keeping that in mind.
I already had a basic understanding of what I was going to do. The simple solution for a hotplate with 0 deviation is to make every observable point have a connected heat source. So we need to make number of heaters as close to infinite as possible. But this is impossible. So my goal was to maximize number of heaters while keeping a set budget of around INR15000 for the heaters.
So I chose 25 cartridge heaters each paired with its own MOSFET and heatsink. My idea was to compartmentalize the hotplate into a square grid on a pcb board such that each MOSFET gets its own PWM signal and I chose a 5X5 grid thus the 25. This enables me to have more control over each point on the wafer and accounts for localised temperature change due to external factors. 25 mosfets need 25 pwm signals so I am using 2 16 channel PWM drivers. More on this in the ppt.
Next would be the PT 100s sensors and all the other equipment which must come with each sensor. This had to lie within another 20k budget. But cost of 25 sensors and other instruments ranged from 50-70k. I realised I could cut all this cost by instead buying a thermal camera. While researching the thought of using a thermal camera to plot temperature gradient across wafer just crossed my mind. And upon further digging I saw a 20k thermal imaging camera which could measure temperature gradient of 40-50mK well within the .5 C margin. This cut costs by about 30k.
But a problem was that these cameras didn't ensure accurate temperature measurement with 2-5 C error in temp measure. 
I realised for an accurate temperature measurement I have no choice but to use 1-2 PT 100s sensors but this is a drastic decrease from the 25 earlier. 
Also since I would be personalizing the PID controller a lot I would need a sturdier microcontroller since I need to process multiple frames of thermal images into a temperature grid so I decided to just make the PID controller instead of buying since it would be more flexible that way.
Another problem was that, in my circuit, the wires would reach temperature of around 400 C. So with some more research I found fibreglass cables which can withstand 600 C.
Now with the logistics out of the way, all that was left was the simple tasks like insulation and power supply etc.
I set out with a budget of around 60k and after accounting for pretty much everything landed at 62-65k.
